# Feeney-Triangle
This repository contains the research, mathematical derivations, examples, and computational verification associated with the Feeney Triangle.
The Feeney Triangle is a recursively generated family of triangular arrays determined by a starting value, a fixed constant, and a binary operator. This project investigates its behaviour under different operators, including addition, subtraction, multiplication, division, and exponentiation.
The repository accompanies the research paper "The Feeney Triangle: A Generalised Recursive Triangle and its Mathematical Properties" by Dominic Feeney.
The project is an ongoing mathematical investigation, with several open problems remaining, particularly concerning general binary operations and the exponentiation variant.
